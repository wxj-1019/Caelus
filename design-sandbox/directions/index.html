Caelus 前端 UI/UX 方向对比稿

同一概览页 · 四种方向 · 浏览器直接打开可交互

Caelus 不只是游戏优化工具——它同样服务开发（编译/构建时释放资源）与系统优化（日常使用的资源守护）。所以这套稿刻意避开了浓玩家味的「竞技/终端」路线，四个方向都按「专业性能守护工具」的定位来做。同一套内容（标题栏 + 侧栏 + 概览页），只改视觉方向，便于直接对比。

Mica 质感 + 系统蓝 + Win11 卡片/导航。「像系统自带工具」的信赖感（PowerToys / 任务管理器风），跨游戏/开发/日常通用。

深色板岩 + 克制的技术感（Grafana / Vercel 风）。数据用等宽、界面用无衬线，专业而不花哨，遥测清晰。
C · 极简 Linear最安静通用全屏查看 →
浅色留白 + 发丝线 + 单一强调色 + 排版驱动层级。干净、耐看、亲和力最高，任何场景都不违和。
D · 精修苹果当前方向基线全屏查看 →
macOS 中性表面 + Apple 强调色 + 微妙高光/辉光。即你现在的方向（精修版），用来和上面三个对照。

怎么选

方向气质适合如果你…代价 / 风险
Windows 原生 Fluent原生、可信赖、专业希望像「系统自带工具」，跨场景通用需要真正接 DWM Mica/Acrylic 材质
开发者控制台克制、技术、清晰常用它做开发/监控，喜欢数据感偏深色专业风，亲和力略低于浅色
C · 极简 Linear干净、安静、高级讨厌装饰感，想要 less is more做过了会显平淡、品牌感弱
D · 精修苹果精致、现代、安静基本满意现状，只想要更精致是微调而非换方向，可能仍不合口味

说明：四稿均为自包含静态 HTML（无需构建/服务器），用真实样例数据呈现，便于横向比较审美。旧的「游戏驾驶舱」「赛博终端」两稿偏玩家向，不符合新定位，已从对比中移除（文件仍在 directions/ 下，想回看可单独打开）。选定方向后，我按项目的 design-sandbox → wpf/Themes/ 映射流程落地成真实主题。
