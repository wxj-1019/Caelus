5/11 项已启用
HAGS 硬件加速 GPU 调度
Windows 图形调度器，部分游戏可降低延迟（需重启）。
VBS 基于虚拟化的安全
Windows Defender 核心隔离，禁用可释放内存并降低 CPU 开销。
中断亲和性优化
将关键设备中断绑定到特定 CPU 核心，减少跨核抖动。
USB 中断亲和性
将 USB 控制器中断固定到非游戏核心，避免输入设备抢占游戏线程。
MSI 中断模式
强制启用消息信号中断，降低 DPC 延迟（部分老设备不兼容）。
设备电源管理
禁止设备进入低功耗状态，避免 USB 外设瞬时掉线。
网络适配器亲和性
将网卡中断绑定到非游戏核心，降低网络抖动对帧时间的影响。
Game Mode 守护
强制 Windows 游戏模式开启，防止系统更新/维护打断游戏会话。
Windows 定时器分辨率
锁定系统时钟分辨率为 0.5ms，降低定时器抖动。
Nagle 算法禁用
关闭 TCP Nagle 算法，降低游戏网络包的排队延迟。
电源计划切换
游戏运行时自动切至高性能电源计划，退出后还原。
