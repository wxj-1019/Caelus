# Caelus WPF 现代工具风重设计验收

日期：2026-08-11

## 设计结果

WPF 前端由 Aurora Bento 全屏玻璃氛围重构为现代桌面工具风：实体分层表面、紧凑设置行、细分隔、6/8px 两档圆角和单一模式强调色。三种性能模式继续映射原业务预设，但模式选择移入侧栏并明确为全局设置；全屏 Ambient 光晕和无限漂移动画不再显示。

页面信息架构调整为：

- 工作台：概览、游戏库
- 游戏调优：优化策略、显卡、反作弊专项
- 系统：系统环境、白名单
- 诊断：系统体检、日志
- 底部固定：设置、关于

## 交互修复

- 页面实例在窗口生命周期内缓存，避免重复导航创建 View 和累积事件订阅。
- 游戏库空态提供添加 CTA 和拖放入口；列表支持真实选中、Delete 键和移除当前项。
- 白名单改用可键盘操作的 ListBox，并补齐运行程序选择器。
- SegmentedControl 在控件层回写 SelectedIndex，保留 TwoWay 绑定。
- 添加游戏对话框会随单项勾选或列表选择刷新添加按钮。
- 设置页显示已有自定义编译进程，着色器状态与更新状态绑定修正。
- Defender 排除和 LOL 附加层不再是占位提示，已接入复用核心 API 的 WPF 工作流。
- WPF 启动和设置页接入既有 UiLight 持久化键，深浅主题可即时切换。
- IconView 对动态主题画刷不再无条件 Freeze，修复离屏和实机渲染异常。

## 视觉矩阵

`CaelusWpf.exe --wpf-shot docs/wpf-redesign` 已成功生成：

- 概览：深色常规、深色竞技、深色自定义、浅色常规
- 深色常规全部页面：游戏库、优化策略、显卡、反作弊专项、系统环境、白名单、系统体检、日志、设置、关于

默认 1196x768 下逐图检查结果：

- 11 个导航页均正确渲染且侧栏选中态同步。
- 未发现文字重叠、水平溢出、空白页面或错误资源占位。
- 长配置页使用统一设置组和设置行，首屏可扫描，滚动条正常。
- 游戏库、白名单、体检和日志空态均有明确状态或主操作。
- 三模式只改变局部身份色；浅色正文、边框和选中态可读。
- 无卡片套卡片、全屏渐变、装饰性光斑或多套圆角混用。

CPU 结果显著低于 Phase 5 Aurora 动画记录的约 `7.8%`。采样进程已使用同权限正常清理。

## 验收边界

- 概览明确标为样例数据预览，不将固定温度、活动或硬件型号冒充实时遥测。
- 未在验收中实际添加/移除 Defender 排除，也未删除 LOL 文件，以避免改变本机安全配置和游戏数据。
- WPF 仍是预览宿主；真实进程守护、生产托盘菜单、单实例和实时遥测迁移不属于本次前端重设计。
