## 需求描述
工程化与质量基建。构建不依赖 Visual Studio：build.cmd 两步出包（临时版生成图标 → 编译带图标与管理员清单的 Caelus.exe，csc.exe/MSBuild 直调），dev.cmd 组成「结束旧实例 → 构建 → 启动」的开发循环，dev.cmd test 把 tests/ 编入并跑全套自测作为提交门禁（FAIL 0 才算过，SKIP 为本机缺能力、不计 PASS）。分发提供 Inno Setup 安装包与便携式 ZIP（放 Caelus.portable 数据落程序目录）；测试代码仅 --selftest 构建编入，发布构建不含。质量实测体系由三层承担：内置自测（271 项，覆盖识别/压制恢复/CPU 拓扑/档案兼容/扫描过滤/体检阈值/场景仲裁等）、--contention-lab 合成争抢台架（A/B 配对量化压制收益）、tools/PerfLab 独立回归守卫台架（真实压制内核多进程 A/B，回答「有没有退步」而非「收益有多少」）。
