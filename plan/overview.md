# 项目计划总览

> 本文件是 planflow 的框架文档入口。表格列出全部里程碑，供与 milestones/ 交叉校验。

**愿景**：为游戏腾出天空——打游戏时把系统资源让给游戏的 Windows 小工具（C# / .NET Framework 4.x，主界面 WPF 棉花糖天空，纯本地零上传）。

I1 = 历史工作整合：把已有功能域按 specs/plans 与代码证据梳理为基线，全部里程碑均属 I1。

|----|------|------|
| M-shell | 应用外壳、品牌与生命周期 | I1 |
| M-ui-theme | WPF 界面与主题系统 | I1 |

| M-suppression | 压制内核与恢复 | I1 |
| M-mode-policy | 三档模式、策略页与白名单 | I1 |
